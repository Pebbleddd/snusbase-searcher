# Snusbase Searcher
A program that uses the Snusbase API to search for data linked to a list of emails that you provide

## How it works

1. Input your Snusbase API Key into `config.json`
2. Input your list of emails into `emails.txt`
3. Optionally input a list of proxies into `proxies.txt`
4. Install packages with `npm i`
5. Run the program by typing `npm run dev` into the terminal
6. Get your results in `output.txt`

## Requirements
- **Snusbase API Key**
- **Node version 20+**
